# README assets

`harnesses/` contains the original, unmodified SVG files downloaded from `https://compressi.us/providers/`. Exact source URLs and SHA-256 hashes are in `sources.json`.

`harness-cards/` places these logos on a charcoal background for readability in GitHub light and dark themes. The Claude card supplies the original SVG’s `currentColor` with Claude’s orange. Aider is shown as a text label: the site lists its integration but has no Aider logo at the checked asset paths.

`badges/` contains static Shields.io badges for platforms, the local gateway, and license terms. The release badge stays live so it follows the latest published GitHub release.

The logo and badge URLs in the profile README are pinned to their asset commit so draft previews and the organization homepage use the same files.
